# External assets

LuckeeMiner intentionally does not bundle Minecraft assets.

Place the required user-provided assets here:

assets/textures/terrain.png
assets/textures/char.png

The game checks for both required assets before starting. If one is missing, it lists the missing path on the bottom screen and waits for START to exit.

The terrain atlas is 256×256. The rd-132328 character atlas is 64×32.
